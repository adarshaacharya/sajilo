Sajilo runs on **Windows 10 and 11, 64-bit**. Installing takes about a minute.

## Download and run the installer

1. [Download Sajilo for Windows](/dl/windows) (**Sajilo-windows-x64.exe**).
2. Open the file you downloaded.
3. Windows may show **“Windows protected your PC”**. This is SmartScreen: beta builds are not code-signed yet, so Windows doesn't recognise the publisher. Click **More info**, then **Run anyway**.

> **Only do this for a file you downloaded from sajilo.fyi or Sajilo's GitHub releases.** If the file came from anywhere else, delete it.

4. Follow the installer. It installs for your account only, so it normally won't ask for an administrator password.

On some Windows 10 computers the installer first downloads **Microsoft Edge WebView2**, which Sajilo uses to draw its window. Stay online until it finishes.

## Put Sajilo on your taskbar

Sajilo lives in the system tray, next to the clock, as a small **Nepal flag**. Windows hides every new tray icon behind the **^** arrow, so the first time you'll need to bring it out:

1. Click the **^** arrow next to the clock.
2. Drag the Nepal flag out of that panel and drop it on the taskbar beside the clock.

![Dragging the Nepal flag from the hidden icons panel onto the taskbar](/assets/docs/windows-tray.png)

Now **hover** over the flag to see today's date, and **click** it to open Sajilo.

## When it's installed

Sajilo opens by itself the first time, and from then on starts with Windows. You can turn that off in **Settings › Display › Startup › Launch at login**.

If you open Sajilo from the Start menu while it's already running, the running copy simply comes to the front.
