Get started in a minute

Beta builds aren't code-signed yet, so each platform shows a one-time security warning on first launch. It takes about 30 seconds, once per update.

macOS

Gatekeeper blocks the app with a two-step warning: drag to Applications, then approve once in System Settings.

Step-by-step guide with screenshots

Windows

SmartScreen flags the installer. Click More info → Run anyway to continue.

Linux

Right-click the AppImage → Properties → allow executing, or run chmod +x before launching.
